# 🐝 Пчелна къща – онлайн магазин за пчеларски продукти

Пълен онлайн магазин с витрина за клиенти, REST API, база данни и админ панел.

| Слой      | Технология                                              |
|-----------|---------------------------------------------------------|
| Frontend  | React 19 + React Router + Vite (`src/`)                 |
| Backend   | Node.js + Express 5 (`server/`)                         |
| База      | SQLite чрез вградения `node:sqlite` (`data/shop.db`)    |
| Админ     | JWT вход, bcrypt пароли, качване на снимки (`/admin`)   |

## Стартиране

Изисква **Node.js 22.13+** (без отделна инсталация на база данни).

```bash
npm install
cp .env.example .env      # задайте ADMIN_EMAIL и ADMIN_PASSWORD
npm run dev
```

- Магазин: http://localhost:3000
- Админ панел: http://localhost:3000/admin – влизате с данните от `.env`
- API: http://localhost:5000/api

При първото стартиране базата се създава автоматично с примерни категории и продукти, а админ акаунтът –
от `ADMIN_EMAIL` / `ADMIN_PASSWORD`. След това паролата се сменя от **Админ → Настройки**.

### Продукционен режим

```bash
npm run build   # компилира frontend-а в dist/
npm start       # Express сервира и API-то, и сайта на http://localhost:5000
```

### Публикуване в Render

Сайтът има нужда от постоянен диск за базата и снимките, затова не работи в serverless хостинг като Vercel.
`render.yaml` описва всичко нужно за [Render](https://render.com):

1. В Render: **New → Blueprint** и изберете това GitHub репо.
2. Въведете `ADMIN_EMAIL` и `ADMIN_PASSWORD`, когато бъдете попитани.
3. Render създава услугата с диск от 1 GB на `/var/data` и публикува при всеки push.

Дискът изисква платен план (Starter). `JWT_SECRET` се генерира автоматично, а `TRUST_PROXY=1` е зададено,
защото Render работи зад прокси.

## Какво може

**Магазин:** начална страница, каталог с категории, търсене и сортиране, страница на продукт, количка
(пази се в браузъра), поръчка с наложен платеж или банков превод, автоматична доставка/безплатна доставка над праг.

**Админ панел:**
- Табло – нови поръчки, оборот, продукти с ниска наличност
- Поръчки – филтър по статус, детайли за клиента, смяна на статус (при отказ наличността се връща)
- Продукти – добавяне/редакция/изтриване, качване на снимка, наличност, скриване, „препоръчан“
- Категории – добавяне, редакция, подредба
- Настройки – име, контакти, цена на доставка, праг за безплатна доставка, лента със съобщение, смяна на парола

Цените се пазят в евроцентове; сумата на поръчката винаги се изчислява на сървъра, а наличността се
проверява и намалява в транзакция.

## Структура

```
server/
  index.js          Express приложение
  db.js             схема на базата, настройки и примерни данни
  auth.js           JWT и защита от brute-force при вход
  routes/public.js  каталог и създаване на поръчки
  routes/admin.js   всичко за админ панела
src/
  pages/            страници на магазина
  admin/            страници на админ панела
  components/       общи компоненти
  lib/              API клиент, количка, настройки, форматиране
data/               база данни и качени снимки (създава се автоматично, не е в git)
```

## API

| Метод | Път                          | Описание                       |
|-------|------------------------------|--------------------------------|
| GET   | `/api/categories`            | категории                      |
| GET   | `/api/products?category=&q=&sort=&featured=1` | продукти      |
| GET   | `/api/products/:slug`        | един продукт                   |
| POST  | `/api/orders`                | нова поръчка                   |
| POST  | `/api/admin/login`           | вход → JWT                     |
| *     | `/api/admin/...`             | products, categories, orders, settings, upload, stats (с `Authorization: Bearer`) |
